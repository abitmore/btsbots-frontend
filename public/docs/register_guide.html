🖥️ 方式一：使用 btsbots-service 图形客户端注册（首选推荐 🌟）

btsbots-service 是为桌面用户打造的开箱即用图形化客户端，内置全套零信任私钥生成与签名风控引擎：

  1. 下载并打开 btsbots-service：在 releases 页面下载对应系统的安装包（Linux deb / macOS / Windows）。
  2. 进入【注册新号】面板：启动后在初始登录门禁卡片中选择【注册新号】。
  3. 填写注册信息：
    • 邀请码：输入您的推荐人邀请码（例如 BTS-9A4B8F21）。
    • 新用户名：输入 8-30 位小写英文开头的账号名（如 mybtsaccount）。
    • 设定保护密码：设置用于加密保存本地私钥的解锁口令。
  4. 自动离线生成与上链：点击【提交注册并直接登录】，程序在本地内存生成 Owner/Active/Memo 密钥对，由推荐人代付链上手续费完成开户。
  5. 凭证自动下载与守护启动：系统会自动在本地下载 mybtsaccount_credentials.txt 密钥备份，同时自动启动签名网关！您可随时在【⚡ 网页登录 OTP】中生成验证码登录网页端。

🐍 方式二：使用 Python 命令行工具注册

适合服务器管理员、量化开发者以及习惯在终端操作的高级用户：

1. 安装极速 Python 工具 uv

# Linux / macOS 系统一键安装：
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows 系统（PowerShell）：
powershell -ExecutionUrl https://astral.sh/uv/install.ps1

2. 克隆仓库并初始化环境

git clone https://github.com/pch957/btsbots.git
cd btsbots
uv sync

3. 执行注册命令

uv run registre_account.py --invite <您的邀请码>

注册成功后本地将自动生成 username_credentials.txt 凭据文件，可运行 uv run sign_bots.py --keyfile username_credentials.txt 启动守护。
